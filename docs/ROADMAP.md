# BellSpire Roadmap

This roadmap grows BellSpire in rings. Each phase should leave the game more playable, more source-governed, and more emotionally alive.

## Phase 1: First-Road Tutorial

- Polish `/login`, character creation, and the first return-to-game flow.
- Improve beginner instructions without turning the interface into a manual.
- Tighten Saint Veyra, Hearthmere Fields, Road Shrine, and Cryptlet command flow.
- Add tutorial feedback for failed or premature commands such as early `loot`.
- Make `listen`, `who`, `party`, `guild`, and `director` feel natural in the first session.

## Phase 2: Social MMO Illusion

- Expand local ambient chat so global, zone, guild, and party channels rotate with less repetition.
- Give simulated players clearer preferences, availability, patience, humor, and trust changes.
- Add party formation beats: invite, accept, decline, ready check, route agreement, post-wipe reaction.
- Make guild recruitment and contracts feel like living boards instead of static cards.
- Keep ambient simulation local by default; reserve API calls for direct interaction and cinematic moments.

## Phase 3: Topographic Map Expansion

- Improve hand-authored world and zone map layers.
- Add stronger terrain identity for fields, roads, coast, glen, vale, shrine routes, and underground spaces.
- Show route safety, locked preview regions, guild hooks, services, and danger at a glance.
- Keep maps schematic but source-governed.

## Phase 4: Loot, Class, And Source Database Hardening

- Expand runtime source governance for future JSON files as they appear.
- Add stricter checks for new rewards, class rows, dungeon rows, source IDs, and rarity.
- Prepare future class support only after source rows and gameplay identity are clear.
- Keep prototype and staged rewards clearly labeled until final loot rows exist.

## Phase 5: Next Playable Candidate

- Choose one adjacent expansion candidate after the first road feels good.
- Likely candidates: Briarwatch Glen / Thornhouse route, Bellscar Coast public event route, or a deeper Saint Veyra social/tutorial route.
- Add one zone/dungeon loop at a time.
- Require a source-governed map, quest, social hooks, loot rules, and tutorial/acceptance notes before declaring it playable.
