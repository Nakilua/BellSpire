# Tutorial Playtest Skill

Use this skill when testing the first BellSpire route.

## Goal

A beginner should be able to create a Bulwark, understand where to go, reach the Road Shrine, enter the Cryptlet, and understand the first combat lessons.

## Test Route

1. Open `/login`.
2. Create or continue a Bulwark character.
3. Confirm the main layout loads.
4. Use `look`.
5. Travel to Hearthmere Fields.
6. Use `listen` and `who`.
7. Travel to Road Shrine of Little Dawn.
8. Talk to Shrinekeeper Olla.
9. Accept the quest.
10. Enter Pilgrim Trial Cryptlet.
11. Use `look`, `continue`, `guard frontline`, and `shield oath`.
12. Try early `loot` and confirm the app explains why it is not ready.
13. Use `recap`.

## Notes To Capture

- Confusing commands.
- Missing tutorial feedback.
- UI readability problems.
- Social chat that feels repetitive or flat.
- Any reward/source-law wording that feels unclear.
- Anything that breaks save persistence.

## Done Means

- Notes are recorded in `docs/TUTORIAL_PLAYTEST_NOTES.md`.
- Bugs are either fixed immediately if tiny or listed as follow-up work.
